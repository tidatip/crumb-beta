# Crumb Beta

ตัวทดลองของ Crumb สำหรับ "แก้แพลนด้วยกัน" แบบเรียลไทม์ (Firebase project crumb-777da)
ข้อมูลในเครื่องแยกจาก Crumb ตัวจริงทั้งหมด — ทริปใน Crumb ตัวจริงไม่ถูกแตะ

เปิดใช้: https://tidatip.github.io/crumb-beta/

- index.html — แอป (ฐาน Crumb v3.18 + แชร์สด)
- vendor.js — Firebase SDK 12.19.0 + qrcode-generator 1.4.4 รวมไฟล์เดียว ใช้ได้ตอนออฟไลน์
- sw.js — แคชสำหรับออฟไลน์
